# APRwithLLM

This repository contains the official code, datasets, experiment scripts and results in our empirical study on **Automated Program Repair with Large Language Models (LLMs)**.

The goal of this project is to evaluate how different LLMs perform on real and algorithmic bugs across multiple languages, and to analyze the effects of model, language and other factors on repair effectiveness.

---

## 📁 Repository Structure

```
APRwithLLM/
├── dataset/        # This folder contains all the datasets used in the experiments. The datasets are organized in separate subfolders according to their types or sources.
├── experiment/     # This folder contains all the scripts used in the experiments.
├── results/        # This folder contains the experimental results corresponding to RQ1 - RQ3. Each research question has its own subfolder within the results directory.
└── README.md       # This documentation
```
